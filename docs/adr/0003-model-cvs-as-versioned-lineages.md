# Model CVs as versioned lineages

A CV is a stable role-and-employer-focused lineage, such as "Product Manager at Google," containing numbered CV Revisions. Each editing session creates the next revision from a selected base, and subsequent changes target that revision without changing earlier revisions. Revision numbers are stored as metadata and only derived into display labels such as "Product Manager at Google · v2," rather than being embedded in the CV's editable name.
