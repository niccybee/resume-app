# Share blocks across CV lineages

CV Blocks belong to a user's reusable library rather than to one CV lineage. CV Revisions reuse content by selecting exact Block Versions through their CV Compositions, so appending a Version for one new CV Revision never changes another Revision that remains pinned to an earlier Version. A Block is duplicated only when the content needs an independently meaningful identity, accepting explicit version selection in exchange for reuse without unintended propagation.
