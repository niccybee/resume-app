# Copy CV Revisions with explicit lineage intent

CV copying uses one cloning mechanism with two explicit user intents. **Copy for New Role** opens an Editing Session for a new CV lineage whose first finished Revision will be Revision 1, while **Copy to New Version** opens another Editing Session in the existing CV. Both may clone a source Revision's CV Composition or an open session's Working Composition, initially reuse the same exact Block Versions, retain source provenance, and leave the source unchanged and open.
