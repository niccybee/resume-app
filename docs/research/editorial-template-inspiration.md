# Editorial template inspiration

Research date: 2026-08-02

These five Resume Studio themes are original CSS compositions built on the app's existing semantic CV renderer. The references below informed typographic systems, grids, spacing, and emphasis only. No source code, artwork, type files, or publication branding was copied.

## Folio

- [Fortune's early editorial system](https://eyemagazine.com/feature/article/wheels-of-fortune): wide margins, a simple two- or three-column grid, and a deliberately small number of type sizes.
- [Inque #1](https://magculture.com/blogs/journal/inque-1): efficient monochrome typography, generous whitespace, and a concise type palette.
- Adaptation: a warm ivory, serif-led CV with three principal type levels and a restrained burgundy signal colour.

## Basel

- [Jacqueline Casey and the MIT Style](https://eyemagazine.com/feature/article/jacqueline-casey-science-and-design): a modular Swiss grid used as a framework for typographic invention, with bold geometric forms and controlled colour contrast.
- [Zweikommasieben #12](https://magculture.com/blogs/journal/zweikommasieben-12): a tightly applied grid, a single type family, and very few point sizes.
- Adaptation: an asymmetric sans-serif CV using black, vermilion, and cobalt as sparse wayfinding signals.

## Gallery

- [Spike #50](https://magculture.com/blogs/journal/spike-50): restrained editorial grid work enlivened by vertical rules and shifts in headline scale.
- [To Think #1](https://magculture.com/blogs/journal/to-think-1): monochrome typography, column rules, and generous negative space.
- Adaptation: a quiet curatorial page with serif/sans contrast, museum-label metadata, and a plum accent on pale mineral paper.

## Dispatch

- [Bloomberg Businessweek's editorial system](https://eyemagazine.com/feature/article/taking-care-of-business): a rigorous grid and detailed typography interrupted by energetic data-like moments.
- [The Fence #26](https://magculture.com/blogs/journal/the-fence-26): a simple two-colour system pairing serif text with condensed, bold headlines.
- Adaptation: a compact news-weekly CV with strong sans headings, crisp labels, and a controlled red signal colour.

## Atelier

- [The Architectural Review's graphic language](https://eyemagazine.com/feature/article/building-a-graphic-language): architectural grids, shifts in column logic, and typographic expression tied to the material.
- [Anima's flexible editorial identity](https://magculture.com/blogs/journal/fran-mendez-anima): a stable grid and typographic foundation that allows measured variation across content types.
- Adaptation: a rational architectural CV with warm stone paper, forest ink, a terracotta accent, and precise technical-label typography.

## Print constraints shared by all five

- A4 portrait surface: 210 × 297 mm.
- System font stacks only; no runtime font or asset dependency.
- Body text remains within the resume-oriented 9.5–10.5 pt range in A4 mode.
- Headings stay with following content; role, employer, entry, and supporting sections avoid internal page breaks.
- Theme backgrounds are preserved with `print-color-adjust: exact` while designs remain readable in monochrome.
- No outer document border, rounded card frame, or theme-owned drop shadow.
